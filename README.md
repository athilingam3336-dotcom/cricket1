# CFVD CricNative - React Native Mobile Application
### Official Mobile App for Cricket Federation of Virudhunagar District (Affiliated to TNCA)

This project is a React Native mobile application converted from the official Cricket Federation of Virudhunagar District (CFVD) portal.

---

## 📱 Features Included

1. **Brand Identity & Header**:
   - Official CFVD Seal with Srivilliputhur Andal Temple Gopuram
   - TNCA Affiliation badges
   - Interactive **Stadium Floodlights Controller** (Night Match / Golden Sunset / Natural Off)
   - Dynamic **Dark & Light Mode** toggle

2. **Live Match Center**:
   - Filter matches by **All, Live, Upcoming Fixtures, and Recent Results**
   - Detailed match cards with team crests, real-time scores, run rates, and batting indicators
   - Interactive **Match Scorecard Modal**:
     - **Match Summary**: Chasing target, current run rates, batsman at the crease, current bowler
     - **Full Scorecard**: Complete batting table (R, B, 4s, 6s, SR), extras, and bowling figures
     - **Ball-by-Ball Commentary**: Color-coded delivery badges (FOUR, SIX, WICKET, 2 RUNS)
     - **Playing XI**: Both squads with Captain (C) and Wicketkeeper (WK) indicators
     - Downloadable official scoresheet action

3. **Season 2026-27 Registration Portal**:
   - Official enrollment modal for Senior & Junior Players, Academy Coaching, Club Affiliation, and Umpires/Scorers
   - Multi-taluk selector (Virudhunagar, Sivakasi, Rajapalayam, Srivilliputhur, etc.)
   - Player specialization picker (Top Order Batter, Pace Bowler, Spin Bowler, All-Rounder, etc.)
   - Generates official `CFVD-XXXXXX` Reference ID tokens

4. **Points Table & League Standings**:
   - Multi-competition switcher:
     - First Division (3-Day Red Ball)
     - Kamarajar Memorial T20 Trophy
     - Andal Temple Inter-School Shield
   - Detailed metrics: P, W, L, D, Bonus points, NRR, PTS, and recent Form pills (W/L/D)
   - Top 4 qualified teams visual highlighting

5. **Player Stats & Cap Leaderboards**:
   - **Orange Cap**: Leading Run Scorers with Innings, Average, Strike Rate, and Runs
   - **Purple Cap**: Leading Wicket Takers with Overs, Best Bowling in Innings (BBI), Economy, and Wickets

6. **Tournaments Showcase**:
   - Virudhunagar First Division League (The G. Parthasarathy Rolling Trophy)
   - Kamarajar Memorial T20 Trophy
   - Andal Temple Inter-School Cup
   - Buchi Babu District Qualifier

7. **Grounds & Infrastructure**:
   - District Sports Complex Stadium (Virudhunagar)
   - Sivakasi Turf Cricket Ground
   - Rajapalayam Cricket Academy Ground
   - Turf pitch, floodlight, pavilion, and seating capacity specifications

8. **District Cricket Academy**:
   - BCCI Level 1 & 2 coaching curriculum
   - High-speed video analysis
   - Yo-Yo fitness benchmarks and direct application CTA

9. **Governance & Apex Council**:
   - Srivilliputhur temple heritage & ethics
   - Honorary Office Bearers: President, Vice President, Hon. Secretary, Joint Secretary, Treasurer

10. **News & Media Circulars**:
    - U-19 selection trial announcements
    - VPL tournament climax report
    - Umpires & Scorers certification clinic with full circular reader modal

11. **Moments Photo Gallery**:
    - Floodlit match chronicles
    - Tap to open full-screen Lightbox photo preview with captions

12. **Federation Secretariat Contact Form**:
    - Direct messaging form to the Honorary Secretary
    - Official phone helpline and email addresses

## 🚀 How to Run the App

Navigate to the `cricnative` directory:

```bash
cd cricnative
```

### Run on Mobile (Android / iOS via Expo Go):
```bash
npm start
```
Scan the QR code in your terminal using the **Expo Go** app on your Android or iOS device.

### Run in Web Browser:
```bash
npm run web
```
or
```bash
npx expo start --web
```

### Run on Android Emulator:
```bash
npm run android
```

### Run on iOS Simulator (macOS only):
```bash
npm run ios
```
